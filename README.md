# RU ⇄ HI Голосовой переводчик (Автосборка на GitHub)

Этот репозиторий настроен так, чтобы вам **не пришлось ничего устанавливать и собирать на компьютере**. GitHub сам автоматически делает две вещи после загрузки файлов:

1. **Для Android** — собирает готовый установочный файл `app-release.apk` (вкладка **Actions → Build Android APK**).
2. **Для iPhone (iOS) и Android** — публикует устанавливаемое PWA-приложение на **GitHub Pages**, которое ставится иконкой на экран «Домой» и работает на весь экран без строки браузера.

---

## Как получить готовое приложение за 3 шага (без терминала)

1. **Создайте новый репозиторий** на [GitHub](https://github.com/new) (можно приватный для APK, или публичный, чтобы работали и GitHub Pages для iPhone).
2. **Загрузите содержимое этого архива** в репозиторий (кнопка **Add file → Upload files** — перетащите все файлы и папки, включая скрытую папку `.github`, и нажмите **Commit changes**).
3. **Заберите готовое приложение**:
   - **Android (.apk):** откройте вкладку **Actions** → дождитесь зелёной галочки у **Build Android APK** (≈5–7 минут) → внизу страницы в блоке **Artifacts** скачайте `ru-hi-translator-android-apk`, перекиньте `.apk` на телефон и установите.
   - **iPhone (iOS):** зайдите в **Settings → Pages → Source: GitHub Actions**, затем во вкладке **Actions** запустите **Deploy iOS & Android PWA to GitHub Pages**. Откройте выданную ссылку в Safari на iPhone → нажмите **Поделиться → На экран «Домой»**.

При первом запуске вставьте свой API-ключ из [Google AI Studio](https://aistudio.google.com/apikey) в настройках приложения.
